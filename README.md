# Campsider Dashboard

Cette page peut être publiée sur GitHub Pages pour la partager facilement.

## Étapes
1. Créez un dépôt GitHub public.
2. Uploadez les fichiers suivants :
   - index.html
   - campsider_dashboard_v2-8.html
3. Ouvrez les réglages du dépôt → Pages.
4. Choisissez "Deploy from a branch", branche `main`, dossier `/ (root)`.
5. GitHub générera une URL publique du type :
   - https://<votre-utilisateur>.github.io/<nom-du-depot>/

Si vous voulez, je peux aussi vous aider à préparer la structure exacte pour un dépôt GitHub prêt à pousser.
